# 新野 NeoBrutal
一款基于 **新粗野主义（Neo-Brutalism）** 的 [Halo 2](https://halo.run) 博客主题。

新粗野主义是一场对当下主流设计（比如苹果式的极简风、圆润的毛玻璃效果）的“叛逆”。它故意抛开那些“精致、优雅”的规则，用很直白、甚至有点“粗糙”的方式，来追求一种极致的真实感、强烈的视觉冲击和独特的个性。

- **作者**：loster
- **预览**：<https://dzbook.top>
- **仓库**：<https://github.com/losterichero/NeoBrutal>
- **环境要求**：Halo `>= 2.19`

## 特性

- **三套配色**：经典粗野（红白档案）、未来粗野（青紫科技）、暖阳粗野（橙黄温暖），一键切换，支持跟随系统明暗 / 手动切换深色模式。
- **硬朗的视觉语言**：粗黑描边、硬投影、红角标记、手作风的排版细节。
- **细腻的动效**：卡片堆叠入场、悬停浮动、点击按压、标签反色、链接手工划线、顶部滚动进度条，并尊重 `prefers-reduced-motion`。
- **封面图渲染**：列表卡片可展示文章封面图，开关可配置。
- **灵活的文章列表布局**：全占满（封面在左、文字在右）或每行两个卡片（封面在上、文字在下），移动端自动单列。
- **首页信息栏**：头像与签名、社交账号链接、站点运行时间、文章/浏览统计。
- **完整页面**：文章、页面、分类、标签、归档、说说、友情链接、评论，支持站内搜索与 Ajax 无限滚动加载。
- **页面布局契约**：实现了 `templates/layout.html` 布局契约，保证与插件页面视觉一致。

## 快速上手

1. 将主题打包为 zip，在 Halo 后台「外观 → 主题 → 安装」中上传启用。
2. 进入「主题设置」，按需配置
3.更多功能，自行探索
